# VolumePie - 방사형 슬라이더 파이 메뉴 (볼륨 믹서・마이크・화면 밝기)

VolumePie는 Windows 마우스 커서 위치에서 시스템 마스터 볼륨, 개별 앱 볼륨 믹서, 마이크 입력 볼륨 및 화면 밝기(내장 디스플레이 WMI + 외장 모니터 DDC/CI + 소프트웨어 조광 폴백)를 즉각적으로 조절할 수 있는 모던 방사형 파이 메뉴(Pie Menu)입니다.

## 3가지 슬라이더 조작 스타일

설정 화면(VolumePie 커스터마이즈 스튜디오)의 '슬라이더 형태 및 조작감' 탭에서 언제든지 원하는 조작 모드로 변경할 수 있습니다:

1. **① 방사형 게이지 모드 (중심에서 바깥쪽으로 드래그)**
   - 파이 메뉴의 각 부채꼴(슬라이스) 자체가 중심에서 바깥쪽으로 향하는 방사형 게이지로 작동합니다.
   - 부채꼴 안에서 안팎으로 드래그하거나 마우스 휠을 회전하여 직관적으로 `0% ~ 100%` 범위를 조절합니다.
2. **② 원주 다이얼 모드 (시계/반시계 방향 회전)**
   - 슬라이스를 선택하고 원의 중심을 기준으로 **시계 방향(+)** 또는 **반시계 방향(-)**으로 회전하듯 부드럽게 조절합니다.
3. **③ 외부 아크 확장 모드 (외부 곡선 슬라이더)**
   - 슬라이스에 커서를 올리면 바깥쪽 둘레를 따라 부드러운 호(아크) 모양의 곡선 슬라이더 바가 펼쳐집니다.
   - 곡선을 따라 핸들을 슬라이드하여 정밀하게 값을 제어합니다.

> **조작 팁**
> - **슬라이더 직접 드래그**: 부채꼴 위를 직접 드래그하여 키 입력 없이 1% 단위로 매끄럽게 조절할 수 있습니다.
> - **마우스 휠 회전**: 원하는 슬라이스에 커서를 두고 휠을 굴려 신속하게 조절합니다 (기본: 3% 단위, 설정에서 1%~10% 변경 가능). `Shift` 또는 `Ctrl` 키를 누른 채 휠을 굴리면 일시적으로 **1% 단위 초정밀 미세 조절** 모드가 됩니다.
> - **오디오 출력 장치 원클릭 전환**: 상단 바 클릭, 휠 스크롤, 또는 키보드의 `D` / `O` 키를 눌러 스피커/헤드폰 등 출력 대상을 즉시 전환합니다.
> - **메뉴 닫기**: `Esc` 키, 마우스 우클릭, 또는 중앙 허브를 클릭하면 즉시 닫힙니다.

## 실행 방법 (트리거)

- **키보드 단축키 (기본값: `Alt + Q`)**
  - 설정 창에서 원하는 키 조합으로 자유롭게 변경할 수 있습니다.
- **마우스 버튼 트리거 (기본값: `휠 클릭(가운데 버튼) 길게 누르기`)**
  - `가운데 버튼 길게 누르기`, `사이드 버튼 1(뒤로) 길게 누르기`, `사이드 버튼 2(앞으로) 길게 누르기`, 또는 `우클릭 + 좌클릭` 중에서 선택할 수 있습니다.
- **스마트 토글 및 홀드 감지**
  - 짧게 클릭하면 메뉴가 열린 상태로 유지(토글)되어 여유 있게 비교·조절할 수 있으며, 길게 누르고 슬라이드한 후 손을 떼면 즉시 자동으로 저장되고 닫힙니다.

## 다운로드 및 설치

1. [Releases 페이지](https://github.com/MametaroGG/VolumePie/releases)에서 최신 설치 프로그램(`VolumePie-Setup-1.0.0.exe`)을 다운로드합니다.
2. 다운로드한 설치 프로그램을 실행하고 화면의 안내에 따라 설치를 완료합니다.
3. 설치가 완료되면 시작 메뉴 또는 바탕 화면 바로 가기를 통해 VolumePie를 실행할 수 있습니다 (기본적으로 시스템 트레이에 상주합니다).
