# VolumePie - スライダーパイメニュー (音量ミキサー・マイク・画面輝度)

Windows のマスター音量、アプリ別音量ミキサー、マイク入力音量、および画面の明るさ（内蔵ディスプレイ WMI ＋ 外部モニター DDC/CI ＋ ソフトウェア調光フォールバック）をカーソル位置で瞬時に調整できるラジアル・スライダーパイメニューです。

## 3つのスライダーパイメニュー操作スタイル（リアルタイム切替対応）

パイメニューを開いている最中に **`Tab` キー** または **`1` / `2` / `3` キー** で、3つのスタイルすべてをその場で切り替えて試すことができます（設定画面の「スライダー形状・操作感」タブからも変更可能）。

1. **① ラジアルゲージ型（中心→外側ドラッグ）**
   - パイの各扇形（スライス）そのものが中心から外側へ向かうラジアルゲージになっています。
   - 扇形の中で外側・内側へドラッグ（またはマウスホイール）することで直感的に `0% 〜 100%` を調整できます。
2. **② 円周ダイヤル型（時計回り・反時計回り回転）**
   - 扇形を選択してドラッグ（またはホールド移動）し、円の中心の周りを**時計回り（＋）**・**反時計回り（ー）**になぞることで滑らかに調整できます。
3. **③ 外周アーク展開型（外周カーブスライダー）**
   - 扇形にカーソルを合わせると、その外周に円弧（アーク）状のスライダーバーが展開されます。
   - 外周のカーブに沿ってつまみをスライドして調整できます。

> **パイメニュー表示中のキーボード操作**
> - **`Tab` キー**: スライダー操作スタイル（ラジアル ⇄ ダイヤル ⇄ 外周アーク）を順次切替
> - **`1` / `2` / `3` キー**: スタイルを直接指定して切替
> - **`Space` キー**: ホバー直接調整モード（クリック不要でカーソル移動のみで値変更）の ON / OFF 切替
> - **`D` または `O` キー**: 音声出力デバイス一覧の展開・収納
> - **`Esc` キー**: パイメニューを閉じる（またはサブページから戻る）

## 呼び出し方法（トリガー）

- **キーボードショートカット（初期設定: `Alt + Q`）**
  - 設定画面から任意のキー組み合わせに変更可能です。
- **マウスボタントリガー（初期設定: `ホイールクリック（中ボタン）長押し`）**
  - `ホイールクリック長押し`、`サイドボタン1（戻る）長押し`、`サイドボタン2（進む）長押し`、`右クリック＋左クリック` から選択可能です。
- **スマート開閉動作**
  - 短く押した場合はトグル表示（開いたままじっくり操作・比較可能）、長押ししてそのままスライドした場合はキー／ボタンを離した瞬間に自動で閉じます。

## ビルドと Inno Setup インストーラー作成

```powershell
.\build-installer.ps1
```

- 実行ファイル出力先: `publish\VolumePie.exe`
- Inno Setup スクリプト: `installer\VolumePie.iss`
- インストーラー出力先: `dist\VolumePie-Setup-1.0.0.exe`
