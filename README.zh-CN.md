# VolumePie - 径向滑块饼图菜单 (音量混音器・麦克风・屏幕亮度)

VolumePie 是一款适用于 Windows 的现代化径向滑块饼图（Pie Menu）菜单。支持在鼠标光标所在位置即时调节系统主音量、独立应用程序音量混音器、麦克风输入音量以及显示器亮度（内置屏幕 WMI + 外接显示器 DDC/CI + 软件调光兜底）。

## 3 种滑块交互操作风格

在设置界面（VolumePie 定制工作室）的“滑块形状与操作手感”标签页中，可随时切换以下 3 种操作模式：

1. **① 径向规模式（由内向外拖拽）**
   - 饼图的每个扇形区域本身就是一个自中心向外发散的径向标尺。
   - 在扇形内直接沿径向向外或向内拖拽（或滚动鼠标滚轮），即可直观地在 `0% - 100%` 之间调节。
2. **② 圆周表盘模式（顺时针/逆时针旋转）**
   - 选中扇形并在圆周上以圆心为基准进行**顺时针（+）**或**逆时针（-）**滑动，体验如机械表盘般顺滑的微调。
3. **③ 外弧展开模式（外周曲线滑块）**
   - 鼠标悬停在扇形上时，其外缘会动态展开一段圆弧滑轨。
   - 沿着外弧曲线滑动滑块手柄即可完成精准调控。

> **操作技巧**
> - **直接拖拽**: 直接在扇形上方按住鼠标拖拽，无需按键即可实现 1% 步长的平滑调节。
> - **鼠标滚轮**: 悬停在任意扇形上转动滚轮快速调节（默认步长 3%，可在设置中自定义 1% 至 10%）。按住 `Shift` 或 `Ctrl` 滚动时将临时进入 **1% 极精细微调模式**。
> - **切换输入/输出设备**: 点击顶部药丸条、在其上滚动滚轮，或按键盘上的 `O`（输出）/ `I`（输入）/ `D` 即可即时切换扬声器或麦克风的默认设备。也可直接在系统托盘右键菜单中快速选择。
> - **关闭菜单**: 按 `Esc` 键、鼠标右键单击任意位置，或点击中心圆形控制核心即可立即关闭。

## 唤出方式（触发器）

- **键盘快捷键（默认: `Alt + Q`）**
  - 可在设置中自由更改为任意快捷键组合。
- **鼠标按键触发（默认: `长按中键滚轮`）**
  - 支持 `长按中键`、`长按侧键1（后退）`、`长按侧键2（前进）` 或 `右键+左键` 触发。
- **智能点按/长按自动识别**
  - 快速点按为切换模式（保持菜单常开以便对比调试），长按并拖拽调整后松开按键将自动保存并关闭菜单。

## 下载与安装

1. 从 [Releases 页面](https://github.com/MametaroGG/VolumePie/releases) 下载最新安装包（`VolumePie-Setup-1.0.2.exe`）。
2. 运行下载的安装程序，按照提示完成安装。
3. 安装完成后，可通过开始菜单或桌面快捷方式启动 VolumePie（默认常驻系统托盘）。
