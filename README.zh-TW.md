# VolumePie - 放射狀滑桿圓環選單 (音量混音器・麥克風・螢幕亮度)

VolumePie 是一款專為 Windows 打造的現代化放射狀滑桿圓環（Pie Menu）選單。支援在滑鼠游標所在位置即時調整系統主要音量、個別應用程式音量混音器、麥克風輸入音量以及螢幕亮度（內建顯示器 WMI + 外接螢幕 DDC/CI + 軟體調光機制）。

## 3 種滑桿互動操作風格

在設定視窗（VolumePie 客製化工作室）的「滑桿形狀與操作手感」分頁中，可隨時切換以下 3 種操作模式：

1. **① 放射標尺模式（由內向外拖曳）**
   - 圓環的每個扇形區塊本身就是一條自中心向外延伸的放射狀標尺。
   - 在扇形內直接沿半徑向外或向內拖曳（或滾動滑鼠滾輪），即可直覺地在 `0% - 100%` 之間調整。
2. **② 圓周轉盤模式（順時針/逆時針旋轉）**
   - 選取扇形並在圓周上以中心點為基準進行**順時針（+）**或**逆時針（-）**滑動，體驗如機械轉盤般滑順的微調。
3. **③ 外弧展開模式（外周曲線滑桿）**
   - 滑鼠懸停於扇形上方時，其外緣會動態展開一段弧形滑軌。
   - 沿著外弧曲線滑動滑桿把柄即可完成精密控制。

> **操作提示**
> - **直接拖曳**: 直接在扇形上方按住滑鼠拖曳，無需按鍵即可實現 1% 步進的滑順調整。
> - **滑鼠滾輪**: 懸停在任意扇形上旋轉滾輪快速調整（預設步進 3%，可在設定中自訂 1% 至 10%）。按住 `Shift` 或 `Ctrl` 滾動時將暫時進入 **1% 極細緻微調模式**。
> - **切換音訊輸出裝置**: 點擊頂部橫條、在橫條上滾動滾輪，或按下鍵盤 `D` / `O` 鍵，隨時一鍵切換揚聲器/耳機輸出。
> - **關閉選單**: 按下 `Esc` 鍵、滑鼠右鍵單擊任意處，或點擊中央圓形控制中心即可立即關閉。

## 呼叫方式（觸發器）

- **鍵盤快捷鍵（預設: `Alt + Q`）**
  - 可在設定中自由變更為任意快捷鍵組合。
- **滑鼠按鍵觸發（預設: `長按滾輪中鍵`）**
  - 支援 `長按中鍵`、`長按側鍵1（返回）`、`長按側鍵2（前進）` 或 `右鍵+左鍵` 觸發。
- **智慧點擊/長按自動辨識**
  - 快速點擊為切換模式（保持選單常開以便對比微調），長按並拖曳調整後放開按鍵將自動儲存並關閉選單。

## 下載與安裝

1. 從 [Releases 頁面](https://github.com/MametaroGG/VolumePie/releases) 下載最新安裝檔（`VolumePie-Setup-1.0.0.exe`）。
2. 執行下載的安裝程式，並依照畫面指示完成安裝。
3. 安裝完成後，可透過開始功能表或桌面捷徑啟動 VolumePie（預設常駐於系統匣）。
